# ระบบสุริยะ 3 มิติ

แบบจำลองระบบสุริยะ 3 มิติที่เปิดในเบราว์เซอร์ ดูดาวเคราะห์โคจรตามตำแหน่งจริง อ่านรายละเอียดของดาวแต่ละดวง และซูมลงไปดูพื้นผิวด้วยภาพความละเอียดสูงสุด 8K

เขียนด้วย [three.js](https://threejs.org/) เป็นเว็บแบบ static ไม่ต้อง build และไม่ต้องติดตั้ง dependency

## ความสามารถ

- **วงโคจรจริง** ดวงอาทิตย์ ดาวเคราะห์ 8 ดวง ดวงจันทร์ และดาวพลูโต อยู่ในตำแหน่งที่คำนวณจากวันและเวลาที่แสดง วงโคจรเป็นวงรีและเอียงตามจริง พร้อมแถบดาวเคราะห์น้อยและแถบไคเปอร์
- **ดวงจันทร์ทุกดวงที่ค้นพบแล้ว** 461 ดวง ได้แก่ ดวงจันทร์ของโลก 1 ดวง ดาวอังคาร 2 ดาวพฤหัสบดี 115 ดาวเสาร์ 293 ดาวยูเรนัส 29 ดาวเนปจูน 16 และดาวพลูโต 5 ทุกดวงมีปีที่ค้นพบ ผู้ค้นพบ และวงโคจรจาก NASA JPL ดวงจันทร์ 28 ดวง (รวมดวงจันทร์ของโลก) มีแผนที่พื้นผิวจริงและคำอธิบายภาษาไทย ดวงอื่นแสดงเป็นก้อนหินรูปทรงจำลอง
- **แผนที่ดาวอังคาร** ชื่อภูมิประเทศสำคัญ 23 แห่ง เช่น ภูเขาไฟโอลิมปัส หุบเขามาริเนริส แอ่งเฮลลัส หลุมเกล และจุดลงจอดของยานทั้ง 11 ลำที่เคยลงจอดบนดาวอังคาร ตั้งแต่มาร์ส 3 (1971) ถึงเพอร์เซเวียแรนซ์และจู้หรง (2021)
- **แผนที่ดวงจันทร์** ทะเล หลุม และเทือกเขาสำคัญ 24 แห่ง เช่น ทะเลแห่งความเงียบสงบ หลุมไทโค แอ่งขั้วใต้–เอตเคน และจุดลงจอด 19 แห่ง ได้แก่ อะพอลโล 11, 12, 14–17 ยานลูนา เซอร์เวเยอร์ 1 ฉางเอ๋อ 3–6 จันทรยาน 3 สลิม โอดิสซีอุส และบลูโกสต์ (2025) ทั้งสองดวงมีเส้นละติจูดและลองจิจูด แตะชื่อเพื่อบินไปดู แล้วกล้องจะหมุนตามดาวให้สถานที่นั้นอยู่กลางจอ
- **ประวัติการค้นพบ** แผงของดาวเคราะห์แต่ละดวงมีกราฟจำนวนดวงจันทร์ที่รู้จักในแต่ละปี และรายชื่อดวงจันทร์ทั้งหมดที่เรียงตามปีที่ค้นพบ ระยะห่าง หรือขนาด เปิดตัวเลือก "ดวงจันทร์ตามปีที่ค้นพบ" แล้วย้อนเวลา เพื่อดูว่าในแต่ละยุครู้จักดวงจันทร์ดวงใดบ้าง
- **รายละเอียดของดาวแต่ละดวง** คำอธิบาย ข้อมูลสำคัญ (ขนาด มวล คาบการโคจร อุณหภูมิ บรรยากาศ ฯลฯ) ขนาดเทียบกับโลก เกร็ดน่ารู้ และระยะห่างจากดวงอาทิตย์กับโลก ณ ขณะนั้น
- **พื้นผิวขยายได้** แตะดาวแล้วกล้องจะบินเข้าไปหา ซูมต่อได้จนใกล้พื้นผิว ภาพจะเปลี่ยนเป็นความละเอียดสูงขึ้นเองเมื่อเข้าใกล้ (4K แล้ว 8K บนคอมพิวเตอร์ หรือ 2K แล้ว 4K บนมือถือ)
- **รายละเอียดของภาพ** เมฆ แสงไฟเมืองด้านกลางคืน และแสงสะท้อนมหาสมุทรของโลก บรรยากาศเรืองแสงที่ขอบดาว วงแหวนดาวเสาร์พร้อมเงาที่ทอดลงบนดาวและเงาของดาวบนวงแหวน ชั้นเมฆของดาวศุกร์ที่ปิดเพื่อดูพื้นผิวจากเรดาร์ได้
- **ควบคุมเวลา** เร่ง ชะลอ ย้อนเวลา หยุด กระโดดไปวันที่ต้องการ (ค.ศ. 1000 ถึง 3000) หรือกลับมาเวลาปัจจุบัน
- **มาตราส่วนสองแบบ** แบบย่อที่ขยายขนาดดาวและย่อระยะห่างให้เห็นทุกดวงพร้อมกัน และแบบมาตราส่วนจริง
- ใช้ได้ทั้งคอมพิวเตอร์และมือถือ รองรับเมาส์ ทัชสกรีน และคีย์บอร์ด

## วิธีเปิดใช้งาน

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ เปิดไฟล์ `index.html` ตรง ๆ ไม่ได้ เพราะเบราว์เซอร์ไม่ยอมให้โหลดโมดูลและภาพพื้นผิวจาก `file://`

```bash
python3 -m http.server 8000
```

แล้วเปิด <http://localhost:8000> เซิร์ฟเวอร์ static ตัวอื่นก็ใช้ได้ เช่น `npx serve`

นำขึ้นเว็บได้ด้วยโฮสต์ static ใดก็ได้ เช่น GitHub Pages โดยเผยแพร่จากรากของ repository ได้เลย

ต้องใช้เบราว์เซอร์ที่รองรับ WebGL 2 (Chrome, Edge, Firefox, Safari รุ่นปัจจุบัน)

## ความถูกต้องของแบบจำลอง

- ตำแหน่งดาวเคราะห์ใช้องค์ประกอบวงโคจรแบบเคปเลอร์ของ NASA JPL ([Approximate Positions of the Planets](https://ssd.jpl.nasa.gov/planets/approx_pos.html)) แม่นยำระดับเศษส่วนขององศาในช่วง ค.ศ. 1800 ถึง 2050 และคลาดเคลื่อนมากขึ้นเมื่อห่างจากช่วงนี้
- ตำแหน่งดวงจันทร์ใช้อนุกรมความแม่นยำต่ำจาก Astronomical Almanac (คลาดเคลื่อนราว 0.3 องศา) ข้างขึ้นข้างแรมจึงตรงกับวันจริง
- แกนหมุนและการหมุนรอบตัวเองใช้แบบจำลองของ IAU ด้านกลางวันกลางคืนของโลกตรงกับเวลาจริง และดวงจันทร์หันด้านใกล้เข้าหาโลกเสมอ
- ภาพทางช้างเผือกวางแนวตามพิกัดกาแล็กซีจริงเทียบกับระนาบสุริยวิถี
- มุมมองแบบย่อใช้ระยะห่างตาม a^0.4 และรัศมีตาม (R/R⊕)^0.45 จึงไม่ใช่สัดส่วนจริง ในโหมดนี้ดวงจันทร์ถูกวางไว้ใกล้โลกกว่าความเป็นจริง
- ดวงจันทร์ของดาวเคราะห์อื่นใช้ค่าวงโคจรเฉลี่ย (mean elements) จาก JPL แล้วปรับเฟสในวงโคจรให้ตรงกับตำแหน่งจากระบบ Horizons ของ JPL 75 ช่วงเวลาระหว่าง ค.ศ. 2016 ถึง 2035 ดวงจันทร์ปกติคลาดเคลื่อนเฉลี่ยไม่ถึง 1 องศา ดวงจันทร์ไม่ปกติวงนอกซึ่งถูกดวงอาทิตย์รบกวนมากคลาดเคลื่อนเฉลี่ยราว 7 องศา ห่างจากช่วงปีนี้ความคลาดเคลื่อนจะค่อย ๆ เพิ่มขึ้น
- ในมุมมองแบบย่อ ระยะของดวงจันทร์ถูกย่อตามจำนวนเท่าของรัศมีดาวเคราะห์ ดวงจันทร์วงในอยู่ที่ระยะจริงเทียบกับวงแหวน ดวงจันทร์ใหญ่ถูกย่อแบบรากที่สอง และดวงจันทร์ไม่ปกติที่อยู่ไกลถูกพับเข้ามาเป็นแถบกว้างไม่กี่เท่าของรัศมี ระบบดวงจันทร์ของดาวพฤหัสบดีจึงอาจซ้อนกับวงโคจรของดาวเคราะห์วงในเมื่อมองจากไกล
- ดวงจันทร์ 370 ดวงยังไม่มีการวัดขนาด จึงวาดด้วยขนาดสมมุติ 4 กิโลเมตร ส่วน S/2009 S1 ดวงจันทร์จิ๋วในวงแหวน B ของดาวเสาร์ยังไม่มีค่าวงโคจรเฉลี่ย จึงมีในรายชื่อแต่ไม่ได้วาด
- พิกัดสถานที่ใช้ระบบของ IAU (ละติจูดเหนือ/ใต้ ลองจิจูดตะวันออก) ตรวจตำแหน่งเทียบกับแผนที่พื้นผิวแล้ว ป้ายชื่อของภูมิประเทศขนาดใหญ่ เช่น หุบเขามาริเนริส ปักไว้ที่จุดกึ่งกลางของพื้นที่ทั้งหมด ดวงจันทร์ในแอปหันลองจิจูด 0° เข้าหาโลกพอดี โดยไม่มีการส่ายเล็กน้อย (libration) แบบของจริง
- แผนที่ของแครอนเป็นแผนที่รุ่นเก่าก่อนยุคนิวฮอไรซันส์ และแผนที่ดวงจันทร์ของดาวยูเรนัสกับไทรทันมีเพียงซีกที่ยานวอยเอเจอร์ 2 เคยถ่ายภาพ

## โครงสร้างโปรเจกต์

```
index.html            หน้าเว็บและโครงของส่วนติดต่อผู้ใช้
css/style.css         รูปแบบการแสดงผล
js/main.js            จุดเริ่มต้นและลูปการวาดภาพ
js/world.js           ฉาก 3 มิติ กล้อง การบิน และการสลับความละเอียดของภาพ
js/astro.js           คำนวณเวลา ตำแหน่ง และการหมุนของดาว
js/shaders.js         GLSL สำหรับพื้นผิว เมฆ บรรยากาศ วงแหวน และดวงอาทิตย์
js/textures.js        ตัวโหลดภาพพื้นผิวแบบแบ่งชั้นความละเอียด
js/ui.js              รายชื่อดาว แผงรายละเอียด แถบเวลา และป้ายชื่อ
js/data.js            ข้อมูลและคำอธิบายของดาวแต่ละดวง รวมดวงจันทร์ที่มีแผนที่พื้นผิว
js/moons-data.js      แคตตาล็อกดวงจันทร์ทุกดวงจาก NASA JPL (สร้างด้วยสคริปต์)
js/catalog.js         รวมข้อมูลดาวทุกดวง ชื่อภาษาไทย และข้อความรายละเอียดของดวงจันทร์
js/swarm.js           วาดดวงจันทร์ดวงเล็กหลายร้อยดวง จุดตำแหน่ง และเส้นวงโคจร
js/scale.js           การย่อขนาดและระยะของแบบจำลอง
js/places.js          ชื่อสถานที่และจุดลงจอดบนดาวอังคารและดวงจันทร์
textures/             ภาพพื้นผิว 1K ถึง 8K ไอคอน และภาพทางช้างเผือก (ที่มาอยู่ใน textures/SOURCES.md)
vendor/three/         three.js r170 และ OrbitControls
tools/                สคริปต์สร้างภาพพื้นผิวและไอคอนจากไฟล์ต้นฉบับ
tests/                ชุดทดสอบการคำนวณทางดาราศาสตร์
```

## การทดสอบ

```bash
npm test
```

ชุดทดสอบเทียบตำแหน่งดวงจันทร์กับระบบ Horizons ของ JPL ในวันที่ไม่ได้ใช้ปรับค่า ตรวจจำนวนดวงจันทร์และข้อมูลการค้นพบ และเทียบผลคำนวณกับปรากฏการณ์จริง เช่น ดาวเคราะห์อยู่ตำแหน่งตรงข้ามดวงอาทิตย์ ดาวศุกร์ผ่านหน้าดวงอาทิตย์ ค.ศ. 2012 สุริยุปราคา 8 เมษายน 2024 จันทรุปราคา 14 มีนาคม 2025 จุดที่ดวงอาทิตย์อยู่ตรงศีรษะในวันครีษมายันและวันวสันตวิษุวัต และมุมเอียงของแกนดาวเคราะห์ ใช้ Node.js 20 ขึ้นไป

## ปรับปรุงข้อมูลดวงจันทร์

เมื่อมีการค้นพบดวงจันทร์ใหม่ สร้างแคตตาล็อกใหม่ได้ด้วยคำสั่งต่อไปนี้ (ต้องเข้าถึง ssd.jpl.nasa.gov ได้)

```bash
tools/fetch_moons.sh cache/jpl
```

```bash
tools/fetch_moon_vectors.sh cache/jpl
```

```bash
python3 -I tools/build_moons.py cache/jpl js/moons-data.js
```

```bash
node tools/calibrate_moons.mjs cache/jpl js/moons-data.js
```

ดวงจันทร์ใหม่จะปรากฏในรายชื่อและในภาพทันที ถ้าต้องการแผนที่พื้นผิวและคำอธิบายภาษาไทย ให้เพิ่มไว้ใน `js/data.js`

## ที่มาของข้อมูลและภาพ

- ภาพพื้นผิวดวงอาทิตย์ ดาวเคราะห์ ดวงจันทร์ วงแหวนดาวเสาร์ และทางช้างเผือก จาก [Solar System Scope](https://www.solarsystemscope.com/textures/) เผยแพร่ภายใต้สัญญาอนุญาต [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) สร้างจากข้อมูลของ NASA ไฟล์ในโฟลเดอร์ `textures/` ถูกย่อขนาดและเข้ารหัสใหม่จากต้นฉบับ
- รายชื่อดวงจันทร์ ปีที่ค้นพบ ผู้ค้นพบ วงโคจรเฉลี่ย และข้อมูลทางกายภาพ จาก NASA JPL Solar System Dynamics: [Planetary Satellite Mean Elements](https://ssd.jpl.nasa.gov/sats/elem/), [Discovery Circumstances](https://ssd.jpl.nasa.gov/sats/discovery.html), [Physical Parameters](https://ssd.jpl.nasa.gov/sats/phys_par/) และ [Horizons](https://ssd.jpl.nasa.gov/horizons/) ดึงข้อมูลเมื่อ 24 พฤศจิกายน 2026
- แผนที่ดาวพลูโต ยูโรปา คัลลิสโต และดวงจันทร์น้ำแข็งของดาวเสาร์ เป็นภาพสาธารณสมบัติจาก NASA, JPL, USGS, SSI, Johns Hopkins APL และ SwRI แผนที่ดวงจันทร์ดวงอื่นจากโครงการ [Celestia](https://github.com/CelestiaProject/CelestiaContent) ภายใต้ CC BY 3.0, CC BY 4.0, CC0 และ CC BY-SA 4.0 รายชื่อผู้สร้างและสัญญาอนุญาตของแต่ละไฟล์อยู่ใน [textures/SOURCES.md](textures/SOURCES.md)
- ข้อมูลทางกายภาพของดาวจาก [NASA Planetary Fact Sheets](https://nssdc.gsfc.nasa.gov/planetary/factsheet/) จำนวนดวงจันทร์เป็นข้อมูลปี 2025
